Swing path

Where the sensor actually went. Position is not double-integrated from acceleration — that drifts without bound and would be fiction within a second. The sensor is treated as a point on a rigid arm turning about a pivot, so position follows from orientation, integrated from the gyro, times a lever arm that is measured rather than assumed.

Both views share one scale, so the overhead view reading as a near-straight line is the finding rather than a rendering choice — the swing barely leaves its plane. Grid squares are 10 cm. Seen from above the casting axis runs up the page, so a forward cast goes up and a back cast goes down, and sideways wander shows as width.

Which way is forward is assumed, not measured. Gravity fixes which way is up but leaves the heading free, so nothing in a handle-mounted IMU says which end of the swing is in front of you. The view assumes the first travelling stroke of a burst is a pickup and therefore goes back. When that is wrong — a burst that opens on a forward cast, say — Flip forward corrects it. It affects this view only: the side elevation reads left-to-right for legibility and claims no direction, and no measurement anywhere in the report depends on the choice.

Colour is which way each stroke turned, measured about the burst's own rotation axis. In casting the colours should alternate, because a back cast and the forward cast after it are one movement run in opposite directions — so two of the same colour in a row means either a missed stroke or a movement that wasn't a cast, and is worth looking at rather than explaining away.

Residual is the share of dynamic acceleration the rigid-arm model fails to explain — lower is a better fit. A burst that never turned fast enough to identify the lever arm is listed but not drawn.

Consistency

Mean spread across arc, duration, peak rate and stop deceleration — lower is more alike. Planarity and peak acceleration are excluded: they track the mount and geometry more than technique.

One column per session, read across. Each column is that session's swing path — side elevation, then the same burst seen from above — over its consistency table. The two views within a session share one scale, but scale is fitted per session, so compare shape and spread here and read absolute sizes off the tables.

Comparison

Each difference is weighed against the stroke-to-stroke variation inside each session. A change smaller than your own noise is not evidence of a real change.

Where the numbers come from. Rotation is measured at the rod handle, so these describe what the caster does, not where the tip goes — tip motion also depends on rod flex, which a handle sensor cannot see.
